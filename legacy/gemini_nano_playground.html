Pasos para activar Gemini Nano en Chrome

Copia estas URLs en tu barra de direcciones de Chrome:

1. Activar modelo base:
chrome://flags/#optimization-guide-on-device-model → Enabled BypassPerfRequirement

2. Activar Prompt API:
chrome://flags/#prompt-api-for-gemini-nano → Enabled

3. Activar multimodal (imagen/audio):
chrome://flags/#prompt-api-for-gemini-nano-multimodal-input → Enabled

4. Ver estado del modelo:
chrome://on-device-internals

5. Verificar en DevTools (F12 → Console):
await LanguageModel.availability() → debe retornar "available"

Nota: Este playground solo funciona en Chrome con los flags activados. En otros navegadores, la API no está disponible.
